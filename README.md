# 智客服 · AI 电商客服自动化 Agent 平台

**仓库地址**：[Gitee（主）](https://gitee.com/jhuas/aics-agent) ｜ [GitHub（备）](https://github.com/jhuas/aics-agent)

面向拼多多中小商家的 **AI 客服 + 经营数据** 一体化自动化平台。程序通过 CDP 接管本机已登录的商家后台，自动接管未读会话、按知识库与记忆库决策回复，并把平台「交易数据-实时」的权威统计同步进本地经营报表。

> 本作品为本地部署的 Windows 应用（绿色版解压即用，无需安装 Python）。因核心能力依赖接管**本机浏览器**中已登录的商家后台，故不提供公网在线地址，以源码仓库形式提交。

---

## 一、解决的传统电商痛点

| 痛点 | 传统做法 | 本作品做法 |
|------|----------|------------|
| 客服响应慢、夜间无人值守 | 人工盯屏，漏回率高 | 引擎周期巡检，自动接管未读会话并回复 |
| 回复口径不一致 | 客服自由发挥 | 知识库统一话术 + 敏感词/极限词过滤护栏 |
| 重复问题反复问 | 每次重新组织语言 | 记忆库复用历史高相似问答，答案稳定 |
| 经营数据口径不一、易失真 | 手工导表、口径混乱 | 统一以「交易数据-实时」权威日统计为准，缺失时明确标注「无在线数据」，不用随机数冒充 |
| 退款/售后拦截不及时 | 事后补救 | 退款类意图即时识别并转人工/拦截 |

## 二、核心功能

**自动客服**
- CDP 接管拼多多商家后台，自动巡检并接管未读会话
- 意图识别 → 知识库命中 → 素材自动发送（图文/视频）
- 敏感词护栏：极限词自动替换、高危词直接拦截
- 退款/纠纷等高风险意图转人工，不误答
- 记忆库：历史问答自动学习与复用（中文 bigram 相似度检索），越用越准
- 演练模式（dry run）：不真实发送，先看决策链路

**经营数据**
- 自动点击交易数据页「实时 / 昨日 / 7日 / 30日 / 周 / 月」逐维度采集并独立入库
- 常驻后台每 30 分钟同步一次，也可在页面「一键更新数据」立即触发
- 严格对账：以权威日统计为基准与本地订单明细逐日比对，偏差超阈值即告警
- 日 / 周 / 月 / 30 天报表统一口径，杜绝「聚合值被当成单日」的数据错位

**驾驶舱**
- 实时日志、引擎启停、统计看板、运营中心、记忆库、图库、API 配置

## 三、技术架构

| 层 | 技术 |
|----|------|
| 前端 | Vue 3 + Vite（构建为静态产物，运行时不需要 Node.js） |
| 后端 | FastAPI + Uvicorn（本地 `127.0.0.1:8000`） |
| 浏览器自动化 | Chrome DevTools Protocol（调试端口 `9222`），复用已登录 Profile |
| 决策引擎 | 知识库规则 → 记忆库检索 → 敏感词护栏 →（可选）DeepSeek 大模型兜底 |
| 数据存储 | 本地 JSON / SQLite，可写数据与只读资源分离 |

## 四、快速开始（源码方式）

**环境要求**：Windows 10/11、Python 3.10+、Chrome 或 Edge

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 准备配置（可选：配置 DeepSeek Key 以启用大模型兜底）
copy backend\config.example.json backend\config.json

# 3. 启动（会自动拉起调试浏览器并打开驾驶舱）
python run_server.py
```

启动后浏览器自动打开 `http://127.0.0.1:8000`：

1. 在自动弹出的调试浏览器窗口中登录 `mms.pinduoduo.com` 商家账号（该窗口需保持打开）
2. 回到驾驶舱点击「**启动引擎**」，输入巡检间隔（默认 30 秒）
3. 建议先开启「演练模式」跑一轮，确认决策链路无误后再关闭

**前端重新构建**（仅修改前端时需要，需 Node.js 18+）

```bash
cd frontend
npm install
npm run build
```

> 仓库已包含 `frontend/dist` 构建产物，直接 `python run_server.py` 即可看到完整界面。

## 六、配置 DeepSeek API Key（可选）

不配置也能运行（走知识库 + 记忆库），配置后可对库外问题启用大模型兜底。

- 方式一：驾驶舱右上角「**API 配置**」填写
- 方式二：编辑 `backend/config.json` 的 `deepseek_api_key`

密钥仅保存在本机 `backend/config.json`，该文件已被 `.gitignore` 排除，不会入库。

## 七、数据口径声明

- 所有成交额 / 订单数 / 退款等指标**只来源于平台在线数据**（「交易数据-实时」权威日统计）
- 无权威日统计时，报表**置空并标注「无在线数据」**，不以本地订单聚合或随机数冒充在线成交
- 存在真实订单但无权威日统计时，订单数据不标注为在线成交
- 数据自检（严格对账）以权威日统计为基准逐日比对，偏差超 5% 红色告警

## 九、注意事项

- 调试浏览器窗口（9222）需保持打开，关闭后引擎无法接管会话
- 首次运行需手动登录商家后台，登录态保存在独立的调试 Profile 中
- 本程序用于商家自有店铺的客服与经营自动化，请勿用于未授权场景
